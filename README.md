# Fertilizer use associated with food, feed, and other crop uses for major crops

This repository contains the R code used in the study “A multidecadal analysis reveals growing competition among food and non-food uses” by Fernando Coello, Josep Peñuelas, and Jordi Sardans.
The study reconstructs long-term nitrogen (N), phosphorus (P), and potassium (K) fertilizer use associated with food, feed, and other uses of four major global crops: wheat, maize, rice, and soybean. The analyses integrate crop-specific fertilizer application rates, harvested areas, crop-use allocation, and international trade.

## Repository structure

scripts/   R scripts used for data processing, analyses, and figure generation
data/      Input datasets required by the analysis
results/   Intermediate and final outputs generated by the analysis
plots/     Figures generated by the plotting script

Large input datasets and processed data underlying the analyses are not duplicated in this GitHub repository.
Data required to reproduce the study are available through the associated Zenodo repository:
https://doi.org/10.5281/zenodo.23529820

## Analysis workflow

The scripts are intended to be run sequentially:

01_Export_Estimation.R
Estimates the fraction of crop production exported using FAOSTAT Food Balance data.

02_TM_Estimations.R
Reconstructs bilateral crop trade and import-source proportions using the trade-matrix approach.

03_Country_Uses.R
Estimates country-level allocation of crop commodities among food, feed, processing, seed, losses, and other uses.

04_Production_Uses.R
Combines domestic-use allocation and trade information to determine the final uses of crop production.

05_Fertilizer_Simulations.R
Generates uncertainty distributions for crop-specific N, P, and K fertilizer application rates and fertilizer use using Monte Carlo simulations.

06_Database_Creation.R
Allocates simulated crop-specific fertilizer use among food, feed, and other uses and calculates global Monte Carlo estimates.

07_Additive_Decomposition.R
Applies an additive Logarithmic Mean Divisia Index (LMDI) decomposition to quantify the contributions of fertilizer application rates, harvested area, and crop-use allocation to changes in fertilizer use.

08_Plots_Creation.R
Generates the main and Extended Data figures and exports the corresponding source-data tables.

## Data availability

The source and processed data underlying the results presented in the study, including source data for the main and Extended Data figures and selected intermediate datasets required to reproduce the analyses, are publicly available through Zenodo:
https://doi.org/10.5281/zenodo.23529820

Source datasets that are publicly available for direct download from their original providers are not duplicated in the repository. Their sources are documented in the manuscript and repository documentation.

## Software

The analyses were conducted in R. Principal packages include tidyverse, readxl, truncnorm, parallel, cowplot, circlize, and flowmapblue.
