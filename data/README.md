# Data

This directory contains input datasets required by the analysis.

Large datasets and processed data are not stored directly in this GitHub repository. Data required to reproduce the analyses are available through the associated Zenodo repository:

https://doi.org/10.5281/zenodo.23529820

Some source datasets are publicly available from external data providers and are therefore not duplicated in the repository. These datasets should be downloaded directly from their original sources, as documented in the manuscript and analysis scripts, and placed in the corresponding subdirectories under `data/`.
