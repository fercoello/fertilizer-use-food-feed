# Results

This directory is used for intermediate and final outputs generated by the analysis scripts.

Generated result files are not stored in this GitHub repository unless required for reproducibility. Relevant processed datasets and source data are available through Zenodo:

https://doi.org/10.5281/zenodo.23529820

Additional outputs can be regenerated by running the analysis scripts after downloading the required input data from Zenodo and, where applicable, from the external sources documented in the manuscript and scripts.
